# App Store release track

No submission is performed by this repository.

Before submission:

- enroll the publishing LLC in the Apple Developer Program;
- reserve the production bundle identifier and create App Store Connect records;
- configure signing outside source control;
- provide support and privacy-policy URLs;
- capture current iPhone/iPad screenshots and accessibility metadata;
- verify the privacy manifest and answer App Privacy questions as “no data
  collected” only while the default no-analytics behavior remains true;
- choose the intended nominal paid price and territories;
- archive, validate, TestFlight-test, and complete export-compliance questions.

The App Store build uses the same source and a publisher-owned bundle identifier.
The GitHub release remains free, open source, and self-signable.
